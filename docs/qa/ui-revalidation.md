## Браузерный прогон явной ошибки

Вторая Vite-сессия `127.0.0.1:5179` направлена на обычный backend из QA/main-основы на `127.0.0.1:8765`, запущенный в новом locked venv интеграционной проверки. Здесь использован штатный ненастроенный provider, без synthetic evaluator.

Через UI импортирован вымышленный EN-диалог `synthetic-qa-ui-error` с двумя сообщениями, затем запущена оценка. Наблюдались очередь, завершение с одной ошибкой и карточка со статусом **«Ошибка»**, текстом о ненастроенном провайдере и кнопкой повторного запуска. В DOM есть `.result-error` и **нет `.score-comparison`**. HTTP-результат: failed, code=provider_not_configured, original_score=null. Неудачный запуск не выдан за успешную оценку; критерии и балл не придуманы. Консоль вкладки не содержала warning/error.

Это реальный HTTP/браузерный путь ошибки конфигурации, **не реальная ошибка внешнего API** 401/429/500/timeout. Последние требуют отдельного provider mock/live прогона. Снимок `ui-provider-error.png` сохранён отдельно от Git.

Нового воспроизведённого функционального дефекта UI в описанном пути не найдено. Это не доказательство отсутствия ошибок во всём приложении. Попытки автоматизации с несовпавшими текстовыми локаторами были исправлены по текущему DOM; они не являются дефектами приложения.

- Реальный LLM, качество RU/KZ/EN ответов, live prompt injection и стоимость этим прогоном не проверялись.
- Реальные DEV/holdout, аудиозаписи, подписанные URL и персональные данные не использовались. Воспроизведение/seek реального звонка не проверено.
- Не повторялись весь набор фильтров, импорт через системный file picker, все редакторские сочетания, клавиатурный/a11y-аудит и null-total в браузере. Null/0/N/A проверены чистыми функциями.
- В main пока нет интегрированного frontend+AI. Для финальной защиты участнику 1 нужно объединить разрешённые ветки; затем повторить основной путь с обычным backend и настроенным провайдером. Участник 4 не выполнял merge.
- Числовую точность AI из этих UI-тестов вычислять нельзя. Исправленная апелляцией оценка не является первоначальным AI-ответом.
