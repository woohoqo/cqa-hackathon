Правила баллов и доказательств

«Да» даёт полный вес, «Нет» — ноль. №4: вес × ответ / 20; №6: вес × ответ / 10. Итог = 100 × сумма баллов / сумма применимых весов, округление только в конце до двух знаков. №8 не меняет балл. При отсутствии применимого положительного веса итог отсутствует.

Для пропущенного действия укажите участок, где оно ожидалось. Для N/A объясните условие неприменимости. В доказательствах используйте ID существующих реплик через запятую. Можно нажать «Вставить ID» возле реплики после фокуса на поле доказательств. Не переносите персональные данные в комментарии. Порог первой реакции в 3 минуты, теги и вложения в оценку не входят.

SHA-256 вычисляется браузером по исходному массиву transcript: порядок сообщений и все поля, включая timestamp, сохраняются; ключи объектов сортируются, JSON без пробелов, UTF-8 без экранирования Unicode. Проверка выполняется до показа и повторно перед экспортом. audio_url в hash не входит. Страница не отправляет сетевых запросов, не использует localStorage и не воспроизводит записи. Автоматическое сохранение на диск отсутствует. Экспорт не содержит текстов диалогов или audio_url.
