# Проверка формы разметки в браузере — 7 ноября 2026

**Статус: BLOCKED средой; UX не подтверждён.** Эта запись не заменяет существующие проверки JavaScript/DOM harness и не объявляет их браузерными тестами.

После успешного browser review приложения предпринята отдельная попытка проверить `qa/annotation.html` через локальный HTTP, чтобы не зависеть от прежней блокировки `file://`. В служебный каталог вне Git скопирован точный HTML; рядом созданы только вымышленные DEV и manifest с одним пилотным RU-диалогом, двумя сообщениями, вычисленным SHA-256 транскрипта и явно синтетическим checklist_hash. Реальные DEV/holdout, персональные данные и аудиоссылки не использовались.

Запуск: `python -m http.server 8184 --bind 127.0.0.1 --directory <служебный каталог>`. HTTP-проверка `http://127.0.0.1:8184/annotation.html` вернула 200; байты ответа совпали с исходным HTML. Это подтверждает доставку страницы, но не выполнение JavaScript, file picker или экспорт браузером.

Открыть страницу не удалось: инструмент управления браузером сообщил, что браузер недоступен; повторная инвентаризация вернула пустой список браузеров. Не было попытки обойти ограничение через другой механизм автоматизации.

Остаются **непроверенными в реальном браузере**:

- выбор локальных DEV/manifest через file picker и проверка SHA-256;
- выбор независимого разметчика A/B;
- заполнение допустимых ответов, evidence IDs и комментариев;
- сохранение draft/complete/disputed и возврат complete в draft после изменения;
- скачивание JSON, его source=human_individual, статус, отсутствие исходных текстов и audio_url;
- восстановление своего экспорта и отказ для чужого разметчика/чек-листа.

Повторить эти действия при восстановлении браузерного доступа, используя исключительно синтетические файлы. Проверить фактически скачанный JSON отдельно. Ни точность AI, ни готовность человеческой разметки из этой попытки не следуют. Это ограничение проверочной среды, а не воспроизведённый дефект самой формы.
