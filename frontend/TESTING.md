# Проверка frontend

## Наборы, запуски и официальная выгрузка — 8 ноября 2026

Новая реализация использует серверные Dataset/EvaluationRun и отдельную официальную выгрузку.
Выполнено в отдельном worktree без браузера и без вызовов модели:

- Node 22.14, `npx --yes pnpm@11 install --frozen-lockfile`.
- `npx --yes pnpm@11 test`: 24 теста (сохранены все 15 прежних).
- `npx --yes pnpm@11 build`: TypeScript и production Vite build.
- `node --experimental-strip-types --test qa/test_ui_contract.cjs`: 10 независимых проверок.
- `git diff --check`.

Новые проверки: числа 0/2/10/100, стабильные равные баллы, null/failed/running в конце,
сортировка полной выборки перед страницами, сохранность выбора, историческая модель/версия/время,
ограничение архива ID запуска, POST официальной выгрузки с командой, точные серверные байты,
отказ скачивания при 422, пустые результаты без выбора запуска, история и апелляции только
одного запуска, имена фактических сетевых попыток FAILED без подстановки настроенных моделей.
Ответы HTTP в unit-тестах контролируемые; это не реальные AI-вызовы.

Интегратору после подключения backend: проверить импорт TEST, выбор набора/запуска после refresh,
массовую оценку, FAILED-only retry (включая двойное нажатие), отдельный DEV/PROD preflight,
warning для допустимого error, скачивание results.json и архивов, фильтры/выбор/сортировку на
нескольких страницах, сохранённые модели и время после смены настройки/чек-листа.
Браузерная и реальная провайдерная проверка новой реализации этим frontend-прогоном не выполнена.

## Интеграция выгрузки результатов

Добавлены кнопки JSON/CSV в списке диалогов. Выгружается ответ штатного endpoint
`/api/v1/exports/evaluations`, включая историю решений в JSON; клиент не собирает
оценки из состояния React и не пересчитывает баллы. Адрес учитывает `VITE_API_BASE_URL`.
Ошибка API или HTML вместо файла показывается пользователю, а не скачивается как результат.

Проверено в отдельном интеграционном worktree: frozen install, `pnpm test` (10/10),
`pnpm build` (TypeScript + Vite), независимые `qa/test_ui_contract.cjs` (10/10),
`git diff --check`. Четыре новых теста используют контролируемый HTTP-ответ и проверяют
адрес, сохранение серверного содержимого/CSV BOM, ошибку API и некорректный формат.
Браузерное скачивание в этом отдельном прогоне не проверялось; его проверяет интегратор
в основном сквозном сценарии.

## Ограничения проверки

AI на проверенном backend возвращал `provider_not_configured`. Успешный сквозной путь проверен
на настоящем HTTP-сервере с контролируемыми синтетическими ответами, а не на реальном LLM.
Финальная демонстрация должна использовать обычный backend после интеграции AI и настройки ключа.
На момент передачи реализация Gemini опубликована в `feat/ai` (`d006fb9`, PR #5),
но ещё не включена в проверенный `main`; реальные запросы Gemini этим frontend-прогоном не проверены.

Реальные записи и подписанная ссылка не использовались. Реальное воспроизведение звонка и CORS
аудиохостинга не проверены. Точный переход по времени сознательно отсутствует: в контракте нет
подтверждённой карты аудио. В больших наборах интерфейс загружает страницы полного списка;
серверная краткая сводка и фильтрация пригодятся для масштабирования за пределы хакатона.

Разные операционные системы и все сочетания полей чек-листа не проверялись. Смена режима
оператор/проверяющий — действие демо-интерфейса, не механизм разграничения доступа.
