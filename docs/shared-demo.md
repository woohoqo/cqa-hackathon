# Временная ссылка для демонстрации

На ноутбуке владельца должны работать backend и Cloudflare Tunnel; интернет и бодрствующий
ноутбук нужны всё время демонстрации. Посетителям достаточно ссылки и пароля команды.
`GEMINI_API_KEY` вводится один раз в `.env` этой копии проекта и не передаётся посетителям.
Завершение туннеля отключает ссылку; новый запуск обычно выдаёт другой адрес.

## Запуск

Сначала выполните установку и сборку frontend из корневого README. Существующий `.env`
не перезаписывайте. В первом терминале из корня проекта:

```powershell
.venv\Scripts\python -m scripts.run_demo
```

Для демо **без пароля**, доступного всем посетителям ссылки, запустите:

```powershell
.venv\Scripts\python -m scripts.run_demo --public
```

В этом режиме доступны интерфейс и API, включая изменения и запуск оценок. Страница
`/demo-login` перенаправляет на приложение. Файл пароля сохраняется без изменений;
обычный запуск без `--public` снова включает вход по паролю. Изоляция базы демо,
серверные ключи, проверка Origin и ограничение адреса API организаторов сохраняются.

Скрипт создаёт `private/demo-access.json`, если файла ещё нет. Откройте этот файл локально:
значение `password` понадобится для формы входа. Существующий пароль сохраняется при
повторном запуске. Файл, логи и база исключены из Git.

Скачайте `cloudflared` из [официального источника Cloudflare](https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/downloads/).
Во втором терминале (ниже предполагается файл `private/tools/cloudflared.exe`):

```powershell
.\private\tools\cloudflared.exe tunnel --url http://127.0.0.1:8001 --protocol http2 --no-autoupdate
```

Откройте выданный **HTTPS**-адрес `*.trycloudflare.com`, введите пароль и передайте
ссылку с паролем участникам. Логин в форме не требуется. Сессия действует до 8 часов.
На обычном HTTP защищённая cookie не работает; для браузера используйте HTTPS-туннель.
Для прямых API-проверок поддерживается HTTP Basic с пользователем `demo` и тем же паролем.

Остановка: **Ctrl+C в обоих терминалах**. После перезапуска результаты остаются на диске.
Чтобы сменить пароль, остановите сервер, замените локальный `password` случайной строкой
длиной не менее 20 символов и перезапустите. Старые сессии перестанут работать.

[Quick Tunnels](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/) предназначены
для временных проверок; постоянный адрес и доступность не гарантируются.

## Данные и ограничения

- Демо принудительно использует `data/demo/cqa.sqlite3` и `data/demo/ai_usage.jsonl`.
  Основная локальная база не подключается к туннелю.
- При пустой базе импортируются четыре явно синтетических входных транскрипта из
  `contracts/demo-conversations.json`. Оценки возникают только после настоящего вызова AI.
- Импорт API доступен через **Импортировать → API организаторов**. Полную подписанную ссылку
  нужно вставить явно; сохранённый серверный секрет не подставляется. Закрытие формы очищает ссылку.
  Группа подставляется из `group_id`; значение в поле можно изменить перед загрузкой.
- Разрешён только точный HTTPS host, порт 443 и путь официального API. Разрешённый endpoint
  извлекается из локального `DEV_API_URL` до его отключения как fallback. Владелец может отдельно
  задать `CQA_DEMO_ORGANIZER_ENDPOINT` (HTTPS origin + путь, без подписи) и перезапустить сервер.
  Запросы на другие адреса и redirects запрещены. Подпись из запроса не сохраняется в БД или `.env`.
- Все загруженные диалоги видны участникам с доступом к сайту; при `--public` доступ даёт сама ссылка. Исходная локальная база по-прежнему
  изолирована; загрузка через API добавляет записи только в базу общего демо.
- Общий пароль даёт всем участникам одинаковый доступ, включая изменения чек-листа
  и решения по апелляциям. Это демонстрационный доступ, не полноценная система ролей.
- Все оценки расходуют квоту серверного Gemini-проекта. Отдельный процесс демо не увеличивает
  квоту Google; не запускайте одновременно большие пакеты из других серверов с тем же ключом.
- Сервер слушает только `127.0.0.1:8001`; защищены также API, документация и выгрузки.
  Чужие browser Origin запрещены; cookie имеет Secure, HttpOnly и SameSite=Strict.

## Фактически проверено 7 ноября 2026

- 391 тест прошёл, 12 необязательных adapter-проверок пропущены, 38 subtests прошли.
- Через публичный HTTPS API выполнена настоящая оценка синтетического RU-диалога моделью
  `gemini-3.5-flash-lite`: статус completed, результат 100, исходный ответ сохранён.
  Это проверка работоспособности, а не измерение точности относительно эталонов.
- Через браузер: форма входа, импорт того же JSON без дубля, открытие сохранённой оценки
  с критериями, N/A и отдельным флагом грубой ошибки. Данные сохранились после перезапуска сервера.
- Проверены отказ без пароля, запрет постороннего Origin и отсутствие доступа к `.env`.
- Ранее выполненные проверки полного процесса, включая новую версию и апелляцию,
  описаны в [integration-report.md](integration-report.md).

Действующие адрес, пароль и идентификаторы фоновых процессов остаются только в локальном
`private/`. Не публикуйте их в репозитории.

## Проверка импорта из формы, 8 ноября 2026

Интегрирован PR #16 Yerasyl, добавлены разрешение точного endpoint в общем демо и компактная
форма с автоматическим выбором группы из ссылки. 421 Python-тест прошёл, 12 необязательных
проверок пропущены, 38 subtests прошли; 15 frontend-тестов, 10 независимых UI-тестов,
annotation harness и production build прошли. Подписанные ссылки и исходные записи в Git не входят.

Настоящий read-only запрос к API организаторов вернул 65 диалогов и 1268 сообщений.
Он не сохранял записи в общую базу. Положительный импорт, повтор без дублей, неизменность подписи,
отсутствие серверного fallback и отказ для чужих адресов проверены на синтетическом mock transport.
Вызовов Gemini для этого изменения не выполнялось.
